### 关键路径（易踩坑）
- **Android SDK 实际位置是 `D:\Application\Android`**（含 android-36、build-tools 36.0.0），环境变量 `ANDROID_HOME`/`ANDROID_SDK_ROOT` 均为空
- 非`D:\Android`，也非 `C:\Users\...\AppData\Local\Android\Sdk`

### 已确认的三个问题
1. `local.properties` 写的是 `sdk.dir=D:\Android` —— 该路径不存在，会导致 `:app:assembleDebug` 失败。README 同一处描述也需一并更正。
2. README 说 API 地址是 `http://10.0.2.2:8080`，但 `app/build.gradle.kts:19` 实际是 `http://120.26.55.209:8080`（阿里云公网 IP）。README 描述已过期。
3. 线上 `http://120.26.55.209:8080/api/categories` 实测返回 HTTP 500
   `{"error":"No operations allowed after connection closed."}`。
   根因是架构缺陷：`server/Main.kt` 把**单个 JDBC Connection 共享**给所有 DAO，
   而 `HttpApi` 用 8 线程固定线程池并发处理；JDBC Connection 非线程安全，
   且 MySQL `wait_timeout` 断连后无重连机制 → 断开后永久 500。
   修复方向：改为每请求获取 Connection，或引入连接池 + 探活重连。
